# Hunter

A job-hunting app for Windows by Soggy Dog Studios. Hunter finds jobs, scores how well each one fits you, writes a
resume for the jobs you pick using only your real experience, and helps you apply on the company's own website.

## Download

Get **HunterSetup.exe** from the [latest release](https://github.com/Soggy-Dog-Studios/hunter/releases/latest) and run it.
No administrator rights needed. Setup downloads the parts Hunter needs (about 400 MB).

Hunter checks for updates once a day and installs them from Settings > About.
